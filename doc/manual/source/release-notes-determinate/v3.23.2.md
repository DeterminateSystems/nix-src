# Release 3.23.2 (2026-10-13)

* Based on [upstream Nix 2.35.3](../release-notes/rl-2.35.md).

## Fix GHSA-25vp-6h23-hj3g, GHSA-92x5-h528-wrmw, GHSA-jwvx-xq5j-gc56, GHSA-m4vq-qf6v-82pj

This release contains critical fixes for security vulnerabilities on Linux and macOS that allows for out-of-bounds heap writes (Linux and macOS), local privilege escalation (Linux and macOS), and Seatbelt sandbox escape (macOS).
These vulnerabilities affect all versions of Determinate Nix prior to 3.23.2, and all versions of upstream Nix prior to 2.35.3, 2.34.9, 2.31.6, 2.30.6, and 2.28.8.
For more details, see the upstream advisories:

* [GHSA-25vp-6h23-hj3g](https://github.com/NixOS/nix/security/advisories/GHSA-25vp-6h23-hj3g)
* [GHSA-92x5-h528-wrmw](https://github.com/NixOS/nix/security/advisories/GHSA-92x5-h528-wrmw)
* [GHSA-jwvx-xq5j-gc56](https://github.com/NixOS/nix/security/advisories/GHSA-jwvx-xq5j-gc56)
* [GHSA-m4vq-qf6v-82pj](https://github.com/NixOS/nix/security/advisories/GHSA-m4vq-qf6v-82pj)

Many thanks to Guthrie McAfee Armstrong, joaoviictorti, faukah, Moritz Theile, and any others for reporting these issues, and thanks to RaitoBezarius, Lisanna Dettwyler, xokdvium, and any others for implementing, verifying, and backporting the fixes.
